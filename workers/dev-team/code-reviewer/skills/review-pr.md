# review-pr

Review a pull request for RBT Trail standards.

## Checklist
- [ ] `npm run check` would pass
- [ ] If `src/` changed → `game/trail.bundle.js` updated
- [ ] If `data/questions.json` changed → `npm run sync` applied to index.html
- [ ] No accidental balance/audit report commits
- [ ] BACB disclaimer intact
- [ ] Agent hooks still registered (verify-trail)
