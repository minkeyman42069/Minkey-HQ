# style-screen

Style a game screen in `index.html` / atlas-artisan tokens.

## Arguments
`$ARGUMENTS` = screen id (menu, map, encounter, ledge, exam, debrief, bestiary)

## Process
1. Find screen section in index.html
2. Use atlas-artisan tokens where possible
3. Test mobile (375px) and desktop (1280px)
4. Check contrast ratios
