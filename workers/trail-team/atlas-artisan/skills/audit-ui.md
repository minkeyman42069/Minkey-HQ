# audit-ui

Audit UI layer in `src/agents/atlas-artisan.js` and related `index.html` screens.

## Process
1. List CSS tokens / design variables from atlas-artisan
2. Map screens: menu, map, encounter, ledge, exam, debrief, bestiary
3. Check mobile breakpoints and touch targets
4. Review hook registrations for UI polish (copy, stats)
5. Flag accessibility issues (contrast, focus states)

## Output
UI audit checklist with file:line references
